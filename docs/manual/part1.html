第 1 章　开始使用

1.1　这套系统帮你做什么

把工程现场每天重复的录入 → 计算 → 判断 → 出日报这几步自动化：

录入 / 导入
观测读数
→
自动算
本次变化
→
自动算
累计与速率
→
自动判
预警 / 报警
→
一键出
Excel 日报

你只需要做两件事：把读数弄进系统（手打或导入），点导出。剩下的变化量、累计、速率、预警等级、报表版式，系统自己算。

几条你可能会关心的能力：

  • 报表按你单位的格式出：把你日常报送的那份整卷日报传上去当母版，以后每期只换数字，封面、签字页、概况、布点图都保留。
  • 多个基坑（或南北两侧）合成一份册子：封面、签字、布点图只留一份，各项目的数据表各占一张。
  • 每期的预警判断和报表上的控制值同源：报表上印的「控制值」就是系统判定用的那个数，不会出现表和系统两套口径。
  • 改过的数留痕：任何更正都保留原值，随时能追溯；没有"改了就查不到"的情况。

1.2　打开系统

项说明
在浏览器里打开 输入管理员给你的地址（单位部署形态一般是 http://服务器地址:8000）。不用装任何软件，Chrome、Edge、QQ 浏览器都可以，推荐 Chrome。
要不要登录 当前版本没有账号体系——能打开这个地址的人就能操作。所以别把地址发到无关的群里；临时给同事演示，用「只读锁定」（见 1.4）。
数据存在哪 存在服务器上的数据库里，不在你电脑上。换台电脑打开同一个地址，看到的是同一份数据。
多久刷新一次 页面不会自动刷新。别人刚导完数据，你要点一下页面上的「刷新」或按 F5 才看得到。

注意：如果页面能打开但一直转圈、或者提示"网络错误"，先别怀疑数据丢了——多半是服务器上那个服务停了。找管理员重启服务即可，数据都在服务器的数据库文件里。

1.5　五条不会让数据出错的规矩

这五条是系统的底线，知道它们你就能放心操作：

  1. 原始读数只增不改。你改一个数，系统不是"覆盖"，而是把旧记录标记为"已被更正"并保留，新值另存一条。任何时候都能查到原值。
  2. 重复导入不会覆盖真实数据。当天已经有真实记录时，导入的行一律「跳过」；只有系统自己生成的演示数据才会被你的数据替换。
  3. 没有日期的数据不入库。系统不会替你猜日期，缺日期的行会单独列出来让你补。
  4. 删项目要输编号、删测点要输点号，而且删前自动备份。随手一点是删不掉的。
  5. 报表上的「控制值」= 系统判定用的数。只有一个出处（预警规则），不会出现表和系统对不上。

反过来说，有三件事你不应该做：

  • 不要在 Excel 里改已经导出、已经报给监理的日报——要改就回系统改数据后重新导出。
  • 不要为了"好看"去改历史期读数（曲线可以拖，但那是更正，会留痕、会重算）。
  • 不要用「彻底删除」代替「归档」——归档保留全部数据，删除不可恢复（虽然有备份）。
