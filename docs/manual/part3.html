第 4 章　批量导入

4.1　两个导入入口怎么选

入口什么时候用关键区别
顶部导航 每日导入 每天把所有基坑的台账一次拖进来，系统按表里的工程名称自动分到各项目。 不绑定项目；不能建点、不能映射点号；分不清的表要你手工指派。
项目内 Excel 导入 只导某一个项目的台账；需要处理"表里的点号系统里没有"这种情况。 能建点、能映射点号、能同步台账里的控制值。

最容易走错的一步：新基坑、批量建测点，不在这两个页面。请回项目列表用「新建项目」或「批量建项目」。
两个导入页都会识别出"点位清单"并提醒你走错门了——看到那条黄色提示，说明你传的文件类型不对。

4.2　Excel 导入（在项目里，一期一个文件）

入口：项目内流程第 ② 步 → Excel 导入。三步：选择文件 → 核对并导入 → 完成。

第 ① 步：选择文件

控件作用注意事项
拖拽区
点击或拖拽 Excel 文件到此处（可一次选多个）		 上传台账，支持 .xlsx / .xlsm / .xls，可多选。 一期一个文件也可以；一个文件里有多个 Sheet 也认。
上传后系统逐个解析，解析是独立的：某个文件失败不影响其它文件。

第 ② 步：核对（这是最需要看懂的一屏）

先看页面顶部可能出现的提示条：

提示条说明什么
这 N 个文件是「点号 + 坐标/高程」点位清单你传的是建项目的清单，不是观测台账。要建项目请回列表用「批量建项目」；如果只是想把它当初始值导入，可以忽略这条继续。
台账里的「控制值」和本项目预警规则对不上表里写的控制值和系统规则里的数不一样。下面会出现一个默认不勾的选项：导入时把台账里的控制值同步到本项目预警规则。要不要勾见 4.2 末尾。
有 N 条数据还没确定观测日期这些行不会导入。去「观测日期（可改）」列给对应数据表选个日期即可。

观测日期（可改）每个 Sheet 一个日期选择器。

表里没写日期、或写错了，都在这里改。

状态解析中… / 解析失败 / 已导入 N 条 / 按新日期核对中… / 待导入 N 条 / 待指定日期 / 无可导入数据。看到 待指定日期，说明这个文件里有行缺日期，去上面那列选。
查看 / 移除切换下方明细 / 把这个文件从本次导入里去掉。移除只是不导这一份，不动已解析的其它文件。

明细区（点「查看」展开）

会按顺序出现最多 8 个区块，对应不同的行：

区块说明系统怎么处理
识别 N 个数据 Sheet告诉每个 Sheet 认出了哪些列（点号=A列、初始值=B列…）。认不出会列出常见原因（表头不在前 15 行、缺少"点号/测值"字样等）。
观测日期每个 Sheet 的生效日期，可在这里改。改完系统会立刻按新日期重新核对：冲突可能变成可导入，反之亦然。
测点匹配（N 个点号在项目中不存在）表里的点号系统里没有。默认已替你选好：能对上已有测点的自动映射，对不上的自动新建。可以逐点改成"跳过"。
这是「Excel 导入」独有的能力，每日导入没有。
✓ 可导入真正会入库的行。右上角有 全部排除（整份文件都不导）。
没有逐行勾选框，只有整份排除。
⚠ 将覆盖系统自动生成的数据这些日期系统生成过演示数据。标记 以你的数据为准（覆盖生成数据），原值留痕。
⚠ 冲突当天已经有真实记录。标记 跳过（不覆盖原始数据），不会有任何覆盖。
⚠ 待指定观测日期缺日期的行。不会导入，补了日期再来。
✗ 校验失败读不通、类型不对等硬错误。不导入，原因那列会写明。

底部按钮

按钮作用注意事项
全部导入（N 个文件 / M 条）
蓝色主按钮		 把当前所有可导入的行一次性入库。 有缺日期行时文案会变成 全部导入（还有 N 条待选日期）。
没有任何可导入文件时按钮是灰的。
重新选择 清空全部文件，回到第 ① 步。 已解析的结果一起清掉。

关于"台账里的控制值和规则对不上"那个勾：

  • 默认不勾——系统不会擅自改你的判定口径。
  • 勾了 = 把台账上写的控制值写进本项目预警规则（只改控制值，报警值不动，因为台账里没有报警值的依据）。
  • 不管勾不勾，数据都会正常入库；同步失败（比如台账控制值比系统报警值还大）也不影响数据。

4.3　每日导入（一次传当天所有台账）

入口：顶部导航 每日导入。同样三步。

第 ① 步：选择文件

控件作用注意事项
拖拽区
点击或拖拽当天的台账到此处（可一次选多个）		 一次上传当天所有基坑的台账。 一份文件里有好几个基坑的表也可以——按表分开认。
补传台账 在已有结果上继续追加文件。 页面已有内容时是追加，不会顶掉刚才传的。

第 ② 步：核对

系统按每张表里写的「监测工程名称」自动找项目。认不出来的会单独摆出来：

区域说明你该做什么
这些表认不出是哪个基坑（N） 列出认不出 / 分不清的表，并给出"为什么没认出来"和"最像的 3 个项目"。 在 分到哪个项目 里选一个，点 指派。指派后这张表会并入下方分组，一起导入。
自动分好的（N 个项目分组 / M 条待导入） 系统已经认准的分组，一个项目一行。 点行左边的箭头展开，可以改观测日期、看冲突与错误明细。

分组表的列

列含义注意事项
项目项目名 + 编号。归档项目会标 · 已归档。

观测日期这一组各 Sheet 的生效日期。展开后可以逐个改；改完自动重新核对。
可导入有日期、能入库的行数。—
要拿主意冲突 N / 错误 N / 缺日期 N；都没有时显示 没有。这三个都不是"阻止导入"，只是提醒你有行不会进。
凭什么认成它匹配依据 + 表里写的工程名称；可能带 请核一眼 / 分不清 标签。带「请核一眼」的一定要看一眼，认错了会导到别的项目。

底部按钮

按钮作用注意事项
全部导入（N 个项目 / M 条） 逐组导入。 有缺日期或某组一条都导不进去时，会先提示（不阻断）再继续。
这一页不同步控制值——要同步请去项目内的「Excel 导入」。
重新选择清空全部，回到第 ① 步。分组和手工指派都会清掉。

4.4　导入结果怎么看：五种行的处理方式

无论哪个入口，导入的行最终只会有五种下场。这张表建议记住：

行的类型判定条件系统处理你能做什么
可导入 日期有、点号能对上（或已选建点）、当天没有真实记录。 入库。 不想导就整份「全部排除」。
覆盖生成数据 当天已有的是系统自动生成的数据。 用你的数据替换，原值留痕。 正常情况，直接导。
冲突 当天已有真实记录（手工录入或以前导入的）。 跳过，绝不覆盖。 要改这一天的数，去记录页做"更正"。
缺日期 表里没写日期、系统也认不出。 不入库（系统不猜日期）。 在「观测日期」列给它选一天，会自动重新核对。
校验失败 数据本身有问题（类型不对、点号空、数值读不通）。 不入库，原因写在表格里。 回原始台账改了再传。

改日期会重置你的选择：在「观测日期」里改过之后，系统会按新日期重新核对一遍，之前做过的「排除」选择会被清空（界面会提示一句）。这不是 bug——日期变了，冲突关系也全变了。

第 5 章　看结果：曲线、对比、预警

5.1　项目列表上的「需要关注」

首页顶部如果出现 ⚠ 需要关注（N） 卡片，说明有事情要处理。三类：

标签含义点「去处理」会去哪
报警 N 项达到报警值，如 QC01 累计 32.5mm 定位到那一天、那个测点的记录页，并提示原因
数据可疑 N 条数据变化异常，如 QC02 单期 8.0mm 请复核 同样定位到那一天，让你核对读数
该观测了 已有 N 天没观测（上次 2026-11-08） 定位到上次观测日
控件作用注意事项
刷新
卡片右上角		重新拉"一句话结论"和"关注项"。只刷这一块，不重载整个项目表。
去处理跳到对应页面并定位。报警条目用的是全部项目（含已归档），所以已归档项目的报警也会出现在这里。

项目表格里几个关键列

列含义注意事项
进度还没建测点 / 已有测点 · 待录数据 / N 个测点 · M 条数据一眼看出这个项目卡在哪一步。
本期概况一句话结论，按预警级别着色。鼠标停上去看"最近观测日期"。
预警状态正常 / 预警 N / 报警 N / 无数据预警/报警标签可以点，点开看明细（哪几个点、累计多少、触发原因）。
下一步按钮文案会自动变：先创建测点 → 录入初始值 → 录入本期数据不知道干什么就点它。
操作导出日报 + 更多 ⌄没有观测数据时「导出日报」是灰的。

控件作用注意事项

分段切换		切换指标。切到位移时分量自动变 X。
X 方向 / Y 方向
仅在水平位移时出现		切换分量。—

拖动调值（这个功能要小心用）

在某条曲线上按住一个点上下拖，可以直接改这一天的读数。适用场景：明显录错了一个数（少打一位、多打一位），不必回记录页翻。

项规则
能拖的点当前指标的曲线上、鼠标距点 16 像素以内。基准点（初始值那天）不能拖；缺测点不能拖。
能拖到哪限制在 ±控制值（累计变化量）之间。拖到头会提示 （已到预警线）。
所以不可能把点拖成报警——报警值不参与限位。
拖完会怎样弹确认框 确认调整这个读数？，显示累计和读数的新旧值。确认后按「更正」保存：原记录保留、标记为已被更正，备注写"曲线图手动调整"。
影响范围只改那一天那个分量。相邻期的"本次变化"和"速率"会跟着变，报表重算。

拖不动的两种可能，别以为是坏了：

  1. 这个项目没配预警规则里的"累计变化量控制值"——没配就没有限位，整个拖动功能直接不生效，界面也不提示。先去配规则（第 7 章）。
  2. 拖的是基准点（最早那一期）。基准是累计的起点，不给拖；要改初始值去测点管理页。

5.3　逐期对比

入口：项目内流程第 ③ 步 → 逐期对比。这一页没有筛选控件，打开就是全量清单，每个"测点 × 观测项"一张卡片。

列含义注意事项
期次初始值 或 第N期。由观测日期自动编号，不能手改。
对比基准这一期跟谁比的日期。首期显示 (初始值)。
对比类型首期(相对初始值) / 相邻上期 / 跨期(中间缺测) / 缺测。看到"跨期"说明中间有几天没测，ΔV 是跨着算的。
读值(m)这一期的读数。缺测显示 -。
本次变化 ΔV(mm)与对比基准之差。颜色跟着预警等级走（金=预警、红=报警）。
累计变化 C(mm)相对初始值的累计。同上。
间隔(天)与基准相隔几天。鼠标悬停会显示 速率 = 本次变化 ÷ N 天。
速率(mm/d)ΔV ÷ 间隔天数。隔了好几天才测一次时，速率会被摊薄——这是速率的定义，不是算错。
变化方向文字描述（下沉/上升等）。受项目里"正值代表"的设置影响。
预警状态正常 / 预警 / 报警。—

5.4　预警事件与数据质量

入口：项目内流程第 ③ 步 → 预警事件。

控件作用注意事项
重新计算预警
