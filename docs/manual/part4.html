6.4　合并报表：南北两侧装订成一份

入口：项目列表 → 工具栏 合并报表。

它解决什么问题：南北两侧（或几个相邻基坑）每天各出一份全套日报，等于打两份封面、两份签字页。合并报表把这些只留一份，数据表各占一张——一天从几十页压到九页。

它不做什么：不动数据、不合并项目。数据仍然各存各的项目、各导各的台账，合并只发生在"打印装订"这一层。

第 7 章　配置

7.1　预警规则：四个格子怎么填

入口：项目列表 → 工具栏 预警规则（规则库视角），或项目行内「更多 → 预警规则」（项目视角）。

先理解"一套规则"

一套规则 = 4 行：沉降·控制值、沉降·报警值、水平位移·控制值、水平位移·报警值。

关键点：一套规则可以作用于好几个项目。几个基坑限值一样时，改一次它们一起变。

弹窗里的控件

控件作用注意事项
规则：下拉 切换正在编辑哪一套。 从项目进来时会自动选中本项目绑定的那套。
项目"借用通用规则"时下拉是空的（草稿状态）。
新建一套清空表单新建。会清空所有已填数值。
删除这套
红字		删掉当前规则套。会解除它与各项目的绑定，这些项目改回套用通用规则。
有气泡确认。
规则名称：如"八号基坑监测方案"。新建时必填；编辑时可留空 = 保持原名。
来源标注：如 GB 50497-2019。选规范预设时会自动带出。
所有项目通用 + 项目多选这套规则给谁用。和母版不同：勾了通用之后，还能再额外指定个别项目，多选框不会禁用。
选择规范预设：一键把某个规范的限值填进 4 行。会整体覆盖当前已填的数值，没有二次确认。改完还能逐格微调。
切换规则套时预设下拉会被清空。

阈值表格：三个格子各管什么

列含义报表上
累计变化限值(mm) 相对初始值总共能变多少。 印在「控制值」第一列
本次变化量限值(mm) 这一期相对上一期跳了多少的上限。不看间隔天数，隔 3 天测也不会被摊薄。 不印，只参与判定
变化速率限值(mm/d) 本次变化 ÷ 间隔天数。 印在「控制值」第二列

三格都可以留空。留空 = 这一维不判（绝不拿 0 当阈值）。判定规则：三样各判一次，取最严的那一级：≥报警值 → 报警；≥控制值 → 预警。

两条硬校验

情况结果
报警值 < 控制值 拒绝保存。红色提示会列出哪一维倒挂，并解释：这样"预警"这一级永远不会出现，一到控制值就直接报警。
报警值 = 控制值 允许，但会提醒：实际只有一级判定（到值就报报警，不会先出预警）。规范做法是报警值比控制值宽一档。

改共用规则会发生什么

两种情况，结果完全不同，一定要分清：

情况保存时
本项目借用的是通用规则（自己没有套） 系统会为本项目单独建一套，不动通用规则、不影响别的项目（自动分叉，安全）。
本项目和别的项目共用同一套 会一起改掉所有共用项目，不会自动分叉。界面只给橙色警告 + 保存时二次确认。
只想改一个项目，请点「新建一套」并只勾那一个。

改完限值之后，旧报表不会自动变。已经导出的文件里印的还是当时的旧数，需要重新导出；要翻出哪些旧文件已经对不上，用「文件检查」（第 8.2 节）。

7.2　沉降不允许回弹（只沉不升）

位置：预警规则弹窗，表格下方那个开关。

适用场景：盖梁支架这类理论上"只沉不升"的观测。测出来的"回升"是测量误差，不该让曲线掉头。

项说明
开启后累计变化的绝对值不再变小；本期被判为回弹时，成果读数取上一期，本次变化记 0、速率记 0。
原始读数照旧存库，记录页查到的还是实测值。改的只是成果口径（报表上印的累计和变化）。
报表自洽「本次测值 − 上次测值」仍然等于「本次变化量」——因为成果读数、变化量、累计都基于同一个数算。
作用范围只对沉降生效。水平位移有来有回是真实变形，不会被抹平。
默认值关闭。基坑这类可能有真实回弹的场景保持关闭。

只勾开关不填阈值 = 只锁方向、不锁大小。回升会被抹平，但一直沉下去也不会报警。要真正约束，必须把「累计变化限值」和「变化速率限值」填上。

判定依据是「这一期的累计变化绝对值，是否比上一期小」，基准是初始值 V0。所以 V0 填错了，累计、回弹判断、控制值比对会一起错。

控件作用注意事项
每个签字栏一行
上传 / 重传 / 删除		 给每个角色传自己的手写签名（白纸黑字，PNG/JPG 都行）。 选完文件立即上传，不用点保存。
没上传的栏留空，不会拿别人的顶替。
也可以直接把 PNG 放进服务器 database/signatures/，文件名用栏名（如 编制.png）。
签名大小
滑块 24~64		 控制签名在报表里的像素高度。 右侧实时显示 px。拖动不会自动保存，要点「保存」。
位置微调 — 左右 / 上下
两个滑块		 左右 ±60px、上下 ±40px。 同样要点保存。右侧有灰字显示 →12 / ↓5 这样的方向。
回正 把两个偏移都归 0。 都是 0 时按钮是灰的。
样张（两张 1:1 示意） 左边是签字页那行（压线居中），右边是数据表那行（紧跟文字）。 拖动滑块约 0.1 秒后重画。所见即所得，导出就是这个尺寸。

测量仪器

控件作用注意事项
已配仪器标签 显示配过的仪器，点 × 移除。 移除只是本地操作，点保存才真正写入。
从常见仪器里选
可搜型号		 预置了几十款常见水准仪/全站仪，按类别分组。 选中只预填名称和型号，出厂编号、检定日期还得手填。
四栏：名称 / 型号 / 出厂编号 / 检定日期 + 添加这台仪器 手输一台仪器。 型号为空时「添加」是灰的。
检定日期是普通文本框，格式手输（如 2025-10-20）。
保存时只有"型号或出厂编号至少一项"的才会存下来。

哪些即时生效、哪些要保存：
即时：电子签名的上传 / 删除。
要按「保存」：三个下拉、天气位置、仪器清单、签名大小、签名左右/上下偏移。
重新读取当前设置 会丢弃未保存的修改，且没有二次确认。
