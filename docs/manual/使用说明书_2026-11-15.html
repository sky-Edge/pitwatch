第 1 章　开始使用

1.1　这套系统帮你做什么

把工程现场每天重复的录入 → 计算 → 判断 → 出日报这几步自动化：

录入 / 导入
观测读数
→
自动算
本次变化
→
自动算
累计与速率
→
自动判
预警 / 报警
→
一键出
Excel 日报

你只需要做两件事：把读数弄进系统（手打或导入），点导出。剩下的变化量、累计、速率、预警等级、报表版式，系统自己算。

几条你可能会关心的能力：

  • 报表按你单位的格式出：把你日常报送的那份整卷日报传上去当母版，以后每期只换数字，封面、签字页、概况、布点图都保留。
  • 多个基坑（或南北两侧）合成一份册子：封面、签字、布点图只留一份，各项目的数据表各占一张。
  • 每期的预警判断和报表上的控制值同源：报表上印的「控制值」就是系统判定用的那个数，不会出现表和系统两套口径。
  • 改过的数留痕：任何更正都保留原值，随时能追溯；没有"改了就查不到"的情况。

1.5　五条不会让数据出错的规矩

这五条是系统的底线，知道它们你就能放心操作：

  1. 原始读数只增不改。你改一个数，系统不是"覆盖"，而是把旧记录标记为"已被更正"并保留，新值另存一条。任何时候都能查到原值。
  2. 重复导入不会覆盖真实数据。当天已经有真实记录时，导入的行一律「跳过」；只有系统自己生成的演示数据才会被你的数据替换。
  3. 没有日期的数据不入库。系统不会替你猜日期，缺日期的行会单独列出来让你补。
  4. 删项目要输编号、删测点要输点号，而且删前自动备份。随手一点是删不掉的。
  5. 报表上的「控制值」= 系统判定用的数。只有一个出处（预警规则），不会出现表和系统对不上。

反过来说，有三件事你不应该做：

  • 不要在 Excel 里改已经导出、已经报给监理的日报——要改就回系统改数据后重新导出。
  • 不要为了"好看"去改历史期读数（曲线可以拖，但那是更正，会留痕、会重算）。
  • 不要用「彻底删除」代替「归档」——归档保留全部数据，删除不可恢复（虽然有备份）。

第 2 章　建项目与测点（第一次用）

一个基坑 = 一个「项目」；基坑里的每个观测点 = 一个「测点」。第一次用，先把这两层建起来，之后每天才有地方录数。

字段作用注意事项

必填		 项目的唯一编号，列表、报表文件名、导出的日报都用它区分。例如 8号基坑、PRJ001。 建好之后不能改（编辑项目时这一格是灰的）。

必填		 项目全称，会印在报表封面上（除非合并报表另填了封面工程名称）。 可以随时改。报表里出现"工程名称"的地方优先用名字全的那个。
地点
可空		 工程位置 / 标段，纯备注性质。 留空就显示 -，不影响任何计算。
沉降读数：正值代表 决定报表和文字结论里把"读数的正方向"说成下沉还是隆起。 两个选项：下沉（多数基坑习惯） / 隆起 / 上升。

列含义报表上

两条硬校验

情况结果
报警值 < 控制值 拒绝保存。红色提示会列出哪一维倒挂，并解释：这样"预警"这一级永远不会出现，一到控制值就直接报警。
报警值 = 控制值 允许，但会提醒：实际只有一级判定（到值就报报警，不会先出预警）。规范做法是报警值比控制值宽一档。

7.2　沉降不允许回弹（只沉不升）

位置：预警规则弹窗，表格下方那个开关。

适用场景：盖梁支架这类理论上"只沉不升"的观测。测出来的"回升"是测量误差，不该让曲线掉头。

项说明
开启后累计变化的绝对值不再变小；本期被判为回弹时，成果读数取上一期，本次变化记 0、速率记 0。
原始读数照旧存库，记录页查到的还是实测值。改的只是成果口径（报表上印的累计和变化）。
报表自洽「本次测值 − 上次测值」仍然等于「本次变化量」——因为成果读数、变化量、累计都基于同一个数算。
作用范围只对沉降生效。水平位移有来有回是真实变形，不会被抹平。
默认值关闭。基坑这类可能有真实回弹的场景保持关闭。

只勾开关不填阈值 = 只锁方向、不锁大小。回升会被抹平，但一直沉下去也不会报警。要真正约束，必须把「累计变化限值」和「变化速率限值」填上。

判定依据是「这一期的累计变化绝对值，是否比上一期小」，基准是初始值 V0。所以 V0 填错了，累计、回弹判断、控制值比对会一起错。

合并报表把多个项目装订成一份册子：封面/签字/布点图共用，数据表各占一张。
规则套一套预警规则（4 行限值 + 适用项目），可以给多个项目共用。
归档项目不再出现在「进行中」列表，数据完整保留，可随时恢复。
只读锁定全站开关，打开后一切写操作被后端拒绝。
