第 8 章　维护

8.1　数据备份与还原

入口：顶部导航 数据备份。

控件作用注意事项
立即备份
主按钮		 立即生成一份数据库完整快照（含全部项目/测点/观测/预警/规则）。 成功提示 备份完成：文件名。
系统在删除项目/测点、还原之前也会自动备份。
刷新 重新读备份列表。 —
备份位置 告诉你文件在哪。 只弹提示，不下载：文件在服务器的 database/backups/ 目录，可直接拷贝保存。
还原
每行红色小按钮		 用这份快照覆盖当前数据库。 破坏性操作。确认框会写明后果。
还原前系统会自动给当前数据再拍一张快照，所以还原本身也能回退。
只读锁定状态下，还原会被后端挡下。

备份列表的列

列含义
ID / 备份文件备份编号和文件名（带时间戳）。
大小自动换算成 KB / MB。
类型手动（你点「立即备份」建的）/ 自动（系统在关键操作前拍的）。
说明 / 创建时间备注与时间。

还原前先想清楚：还原会把"从这份快照之后的所有操作"抹掉——包括别人今天刚导的数据。
还原后如果发现不对，用刚才自动生成的那份快照再还原一次就能回来（但记住：这期间的操作不会自动恢复）。

8.2　导出文件检查

入口：顶部导航 文件检查。作用：把你已经导出的日报和系统里的数逐个比对，防止"报表印错了还没发现"。

控件作用注意事项
路径输入框
占位：导出日报统一存放的那个文件夹		 填要扫描的文件夹绝对路径，如 D:\文件\测量台账\导出日报。 进页面会自动带出上次记住的路径。回车即开始检查。
浏览… 打开文件夹选择弹窗（后端列目录，因为浏览器拿不到绝对路径）。 单击进文件夹，双击直接选中并回填。
记住这个文件夹 存进系统设置，下次打开自动带出。 路径为空时按钮是灰的。
开始检查 扫描并逐份比对。 文件多时会慢，界面会显示已用秒数。
只读，不改文件也不改数据。
导出结果 CSV 把明细导成 CSV（带 BOM，Excel 打开不乱码）。 导出的是全部明细，不受上面的标签筛选影响。

它比对什么

  • 变化速率 / 本次变化量 / 本次累计变化量是否和系统一致；
  • 变化速率和累计有没有超过预警规则；
  • 报表上印的「控制值」和现行规则是不是同一个数；
  • 报表判的等级和系统判的等级是否一致。

结果怎么看

区域说明
汇总行 扫到 N 个文件，比对 M 份、共 K 行扫描范围与规模。
有问题的行：N红色表示有问题，绿色表示干净。
问题类型标签（可点击）点一下按类型筛选表格，再点取消。类型包括：速率不一致、变化量不一致、累计不一致、超速率、超累计、控制值对不上、判级不一致、测点不存在、报表空、系统无数据等。
明细表列项目 / 观测日期 / 测点 / 观测项 / 变化速率 / 本次变化量 / 本次累计 / 问题 / 来源。
报表值和系统值不一致时会并列显示（报表值红色加粗）。来源 列写明出自哪个文件、哪个 Sheet、第几行。

三种"不是错误"的提示

提示含义与处理
有 N 份日报的基坑名和系统里的项目名不是完全一样，是按「相近」认的 报表里的工程名带地名前缀、中文数字、括号限定，系统会按相近认。下面会列出"认成哪个项目、报表里写的是什么"，扫一眼确认没认歪——认错了会比对出一堆假问题。
有 N 个文件没能检查 认不出是哪个项目。会告诉你"最像的是谁（相似度）"。要查就先确认文件到底是哪个项目的。
有 N 份属于已归档项目，本次没查 归档项目的旧报表再报"对不上"也没意义，默认跳过。要查就先在列表里「恢复在用」再跑一次。

每周提醒：如果配了检查文件夹、且距上次检查超过 7 天，打开系统时项目列表顶部会出现橙色提醒 该检查一下导出的日报了，点「去检查」直接过来。
系统没有常驻定时器（关了就不跑），所以做成"打开系统时补扫"。

8.3　归档与彻底删除

操作入口说明
归档项目 行内「更多 → 归档项目」，或勾选多个后点批量栏 归档 推荐做法。归档后不再出现在「进行中」列表，数据完整保留，可随时「恢复在用」。
有二次确认。
恢复在用 行内「更多 → 恢复在用」，或批量栏 恢复在用 直接执行，没有二次确认（因为无害）。
彻底删除项目 行内「更多 → 彻底删除…」 必须手动输入项目编号才能点下确认按钮；删除前自动备份；同时删掉全部测点、观测数据、预警事件与规则。
不可恢复（除非用备份还原）。
停用测点 测点管理页行内 停用 软删除，数据保留，可「恢复」。
彻底删除测点 测点管理页行内 删除… 必须输入测点编号；删除前自动备份；连带删掉该点全部观测记录和预警事件。
只有建错点、重复点才用。

有观测数据的项目/测点，请一律用「归档 / 停用」。物理删除只适合"建错了、还没用过"的对象——虽然系统会备份，但还原一次要把后面所有人的操作一起回退。

9.2　常见提示与处理办法

看到这句话它是什么意思 / 怎么办
当期是只读模式 —— 所有修改都会被拒绝只读锁开着。去列表页把那个开关关掉。
本期数据无变化，无需保存你填的数和系统里已有的一模一样，没必要再存一次。
系统不会替你猜日期有行缺日期。去「观测日期」列补选一天，会自动重新核对。
跳过（不覆盖原始数据）当天已有真实记录，导入不会覆盖。要改数请去记录页做"更正"。
以你的数据为准（覆盖生成数据）当天是演示数据，你导入的会替换它。正常情况。
先别导出 —— 有 N 处会让这份报表出错母版体检没通过。按红色提示改，改完点「改好了，重新体检」。
母版体检有必须先处理的问题，改好后才能导出鼠标停在灰掉的导出按钮上出现的提示。同上。
这些日期不是两侧都有数据：2026-11-15合并报表要求同一天各项目都有数据。换一天，或等另一侧补测。
报警值不能低于控制值填反了。这样"预警"永远出不来，一超就直接报警。
这套规则还被另外 N 个项目使用改限值会一起改掉它们。只想改一个，先「新建一套」并只勾该项目。
本项目目前借用的是通用规则保存后会为本项目单独建一套，不动通用规则。
母版里的段落格子不够放本期内容文字太长装不下，换一份预留段落更多的母版。
网络错误 / 请求超时服务停了或网络断了。刷新页面；仍不行找管理员重启服务。

9.3　数据安全的六条底线

  1. 不要在 Excel 里改已导出的日报，要改就回系统改数据后重新导出。
  2. 不要用「彻底删除」代替「归档 / 停用」，除非是建错且没用过的对象。
  3. 改共用规则前先看清楚它影响几个项目（弹窗会写），只想改一个就新建一套。
  4. 还原备份前先确认时间点，因为这会抹掉之后的所有操作。
  5. 演示前打开「只读锁定」，演示完记得关。
  6. 每周跑一次「文件检查」，别等监理发现报表数不对。

附录　术语表

术语含义
项目一个基坑（或一处独立工点）。数据、报表、规则都以它为单位组织。
测点一个观测点，如 JJC1。一个项目下可以有多个测点。
观测项 / 分量测点测什么：沉降（value）、水平位移 X、水平位移 Y。
V0（初始值）累计变化的起算基准。优先用测点上手工指定的；没指定则取首期有效读数。
本次变化 ΔV这一期相对上一期（或最近有效一期）的变化量。
累计变化 C这一期相对 V0 的变化量。
速率ΔV ÷ 间隔天数（mm/d）。隔几天测一次时会被摊薄。
控制值 / 报警值两级阈值。超控制值 = 预警，超报警值 = 报警。三样各判一次，取最严。
缺测这天没测（录入时留空）。会生成一条"缺测"记录，不参与后续比较。
更正改已有读数。旧值保留并标记"已被更正"，新值生效。
母版你上传的整卷 Excel 样板（封面/签字/数据表全套）。导出时复制它、只换数字。
合并母版含多张数据表、每张装一个项目的母版，只能用于「合并报表」。
合并报表把多个项目装订成一份册子：封面/签字/布点图共用，数据表各占一张。
规则套一套预警规则（4 行限值 + 适用项目），可以给多个项目共用。
归档项目不再出现在「进行中」列表，数据完整保留，可随时恢复。
只读锁定全站开关，打开后一切写操作被后端拒绝。
