第 2 章　建项目与测点（第一次用）

一个基坑 = 一个「项目」；基坑里的每个观测点 = 一个「测点」。第一次用，先把这两层建起来，之后每天才有地方录数。

2.1　新建项目：每个字段怎么填

入口：项目列表页 → 工具栏 新建项目（蓝色主按钮）。

字段作用注意事项
项目编号
必填		 项目的唯一编号，列表、报表文件名、导出的日报都用它区分。例如 8号基坑、PRJ001。 建好之后不能改（编辑项目时这一格是灰的）。
建议用能一眼对上的写法，别用 001 这种过两天自己都分不清的。
项目名称
必填		 项目全称，会印在报表封面上（除非合并报表另填了封面工程名称）。 可以随时改。报表里出现"工程名称"的地方优先用名字全的那个。
地点
可空		 工程位置 / 标段，纯备注性质。 留空就显示 -，不影响任何计算。
沉降读数：正值代表 决定报表和文字结论里把"读数的正方向"说成下沉还是隆起。 两个选项：下沉（多数基坑习惯） / 隆起 / 上升。
填错了不会算错数，但报表上"下沉/隆起"的说法会反——拿不准就保持默认，它只影响措辞。
水平位移读数：正值代表 同上，决定位移方向说成向基坑内还是向基坑外。 选项：向基坑内（多数基坑习惯） / 向基坑外。

一个容易被忽略的点：项目的编号和名称、方向设置，都可以在项目行的「更多 → 编辑项目」里改（编号除外）。建项目时不用纠结太久。

2.2　先看个示例：不填任何数据先跑通

入口：项目列表页 → 先看个示例（烧瓶图标）。

控件作用注意事项
先看个示例 一键建一个演示项目：固定 8 个测点、自动配好预警规则、自动生成 3 期演示数据。 建完就能直接看曲线、导日报，用来熟悉流程。
演示项目和你自己建的项目没有区别，用完可以在行内「更多 → 彻底删除」删掉。
按钮点击后会转圈，防止连点重复建。

2.3　批量建项目：一张清单建好几个基坑

入口：项目列表页 → 批量建项目。适用场景：一次测量采集了好几个基坑的点位清单（点号 + X/Y/Z 坐标）。

先确认入口别走错：这里要的是点位清单（点号 + 坐标/高程），不是逐期观测台账（那种表里有"观测日期""本次测值"）。逐期台账请进项目后用「Excel 导入」。

第 ①／② 步：上传清单

控件作用注意事项
拖拽区 / 点击或拖拽清单文件到此处 上传点位清单（.xlsx / .xlsm / .xls）。 一次只能传一个文件，重新上传会整体覆盖上次的结果。
表里只要有点号和坐标/高程就行，有没有表头都能认。
解析结果条
读到 N 个点 ｜ 数据表：xxx		 显示识别到多少个点、从哪个 Sheet 读的、各列对应关系。 会提示 X/Y 是根据坐标数值大小自动判的，核对一下有没有判反（X 一般 341 万量级，Y 一般 51 万量级）。这句要认真看，判反了平面布置图会横竖颠倒。

第 ② 步：分组与点号规则

系统会按点号尾部序号猜一次分组（比如 JJC1~JJC8 一组、JJC9~JJC16 一组），猜错可以逐行改。

控件作用注意事项
所属基坑（可改）
表格里每一行		 给这个点选一个基坑，可以直接输入新名字。 没分组的行整行有底色，一眼能看出来。
系统无法自动分组时会提示 没能自动分组，请在表格里给每行选一个基坑（可以勾选多行一起归类）。
批量归类工具条
输入框 归到哪个基坑 + 按钮 归到这个基坑		 先勾选多行，再输入基坑名，一次归好。 按钮没勾选行、或名字没填时是灰的。
项目编号 / 项目名称
每组两个输入框		 这组要建成（或复用）哪个项目。 如果名字和系统里已有项目一致，会显示 已有项目「xxx」→ 直接用它，不会重复建。
该项目已有测点时还会提醒你注意点号别撞。
初始值日期
每组一个，必填		 这一组的初始值（第 0 期）算哪一天测的。 没有默认值，必须手选。没选就点生成会被拦下并点名是哪几组。
顶部有 统一设为这一天 + 应用到全部，多组同一天时用它省事。
点号规则
前缀 / 起始序号 / 补零位数		 把清单里的原始点号，按规则重新编成系统里的点号。 默认：前缀 JJC、起始序号 1、不补零 → 生成 JJC1、JJC2…。
组内按清单出现顺序编号，不沿用表里的原编号。右侧会实时显示区间（如 JJC1 ~ JJC12）。
取消这个分组 把这一组拆掉，点退回"未分组"。 只取消分组，不删点，重新分就行。

第 ② 步底部：生成

控件作用注意事项
生成 N 个项目（M 个测点）
主按钮		 一次创建全部项目、测点、初始值记录。 点之前会校验三件事：有没有分组、每组有没有选初始值日期、每组有没有填点号前缀。缺一项就停下并告诉你缺哪组。
同名测点会跳过，不会覆盖它的初始值。
重新选择 清空解析结果和分组，回到上传。 已分好的组会一起清掉，注意别误点。

第 ③ 步：完成

结果会逐组列出：组名 → 项目「名称」（编号）【新建】/【复用已有】：测点 N 个、初始值 M 条、日期 2026-03-05。有跳过的点会单独点名并给出原因。

2.4　测点管理：新建、编辑、停用、彻底删除

入口：项目列表 → 行内「下一步」按钮（先创建测点 / 录入初始值），或「更多 → 测点管理」。

页面工具条

控件作用注意事项
新建测点
主按钮		逐个建点。见下方字段表。
批量新建
加号图标		粘贴多行文本一次建多个点。见 2.5。
观测录入跳到记录页开始录当天读数。测点建好后才有意义。
显示已停用：
开关，默认开		是否把停用的测点一起列出来。关掉后列表只剩在用点。停用的点数据仍在，只是不再出现在录入表里。

新建 / 编辑测点弹窗

字段作用注意事项
测点编号
必填		 点号，如 JJC1、QC01。项目内唯一。 编辑时不能改。建错点号只能删掉重建。
观测类型
必填，无默认值		 这个点测什么：沉降 / 水平位移 / 沉降 + 水平位移。 决定录入时要填几个数：沉降 1 个、位移 2 个（X/Y）、两者都要 3 个。新建时必须手动选，不会替你默认。
显式初始值 V0(mm，可选) 手工指定这个点的初始读数（毫米）。 强烈建议留空——留空时系统取"首期有效读数"作为 V0（推荐默认行为）。
只有在你确实有一份独立的初始值采集成果时才填。
这里填的是毫米，注意和录入时的"米"区分。
位置描述 现场位置备注，如 1#钢板桩桩顶 / 桩号 K2+100。 会显示在顺序录入面板上，方便核对。可空。

表格与行操作

列 / 按钮含义注意事项
ID数据库内部编号。日常用不到。
测点编号 / 类型 / 位置描述建点时填的内容。位置为空显示 -。
初始值(mm)显式指定的 V0（毫米原值）。显示的是毫米；记录页显示的是米，别以为是两套数。
状态在用（绿）/ 已停用（灰）。停用不删数据。
编辑改名称、类型、初始值、位置。停用的点也能编辑。
停用软删除：不再出现在录入表里，数据全部保留。确认框问 确定停用测点 xxx？。
日常建议用这个，不要用删除。
恢复把停用点改回在用。没有二次确认，点了就恢复。
删除…物理删除：连同该点的全部观测数据、预警事件一起删。必须手动输入测点编号才能点确认按钮。
删除前系统自动备份数据库，但不要依赖它——有数据的点请用「停用」。

2.5　批量新建测点：粘贴一堆点号

入口：测点管理页 → 批量新建。

第一步：粘贴文本

文本框里一行一个测点，格式：

编号,类型,初始值(mm，可空),位置(可空)

字段说明
编号点号。这一格为空的行会被跳过。
类型settlement/沉降、displacement/水平位移、both/沉降+位移。认不出来时按 both 处理。
初始值毫米。只有能转成数字才写入，写错字就留空（等于走"首期读数自动作废 V0"）。
位置位置描述。

分隔符用逗号、中文逗号、分号、Tab 都可以。表头行（含"编号/点号/point"且只有两格）会自动跳过。

示例：

JJC1,both,4907000,1#钢板桩
JJC2,settlement,,2#钢板桩
JJC3,displacement,3413055112,3#钢板桩

第二步：预览与创建

控件作用注意事项
校验并预览 先解析、不落库，把每一行的校验结果列出来。 一行都没解析出来会提示格式写法。
预览表格的校验结果列 三态：可创建（绿）/ 跳过（原因）（橙，通常是已存在）/ 错误（原因）（红）。 只有「可创建」的会被提交。
← 返回编辑 回到文本编辑，改完再校验。 返回会清空预览行。
确认创建 N 个测点 真正落库。 可创建数为 0 时会提示"没有可创建的测点（全部冲突/错误）"，不提交。

2.6　测点平面布置图

测点管理页上方会自动画一张平面图（有坐标数据时才出现）。

控件作用注意事项
坐标数值 开关，默认开 在每个点下方显示 X / Y 坐标。 点挤在一起时可以关掉。
相邻间距 开关，默认开 画相邻点之间的虚线和距离（如 12.5 m）。 按点号顺序连，不是按实际相邻关系算的。
范围框 开关，默认开 画所有点的外包虚线矩形。 只是包络框，不代表围护结构或基坑边界。
收起图 / 展开图 折叠图形，给下方表格让出空间。 收起后显示 图已收起（N 个点，范围 W m × H m）。

为什么有的点画不上：平面位置取的是水平位移的 X/Y 首期读数。纯沉降点没有 X/Y、或者缺 Y 的点，画不出来。系统会把画不上的点点名列出来，不会静默少点。

第 3 章　录数据（每天用）

3.1　观测记录页：先认清楚这块界面

入口：项目内流程第 ② 步 → 逐日录入。

控件作用注意事项
日期选择器
工具条最左，默认今天		 切换"正在录哪一期"。 从「需要关注」点进来时会自动定位到有问题的那一天。
日期不能清空；没有测点时是灰的。
保存本期观测
蓝色主按钮		 保存当前日期、当前表格里所有测点的读数。 保存是整张表的，不能只存一个点。
"留空"也会被保存成一条"缺测"记录——这是有意的，等于告诉系统"这天没测"。
自动生成数据
闪电图标		 打开演示数据生成器（见 3.5）。 日常真实观测不要用它。
总览表格 / 顺序录入
分段切换		 两种录入方式。 数据是同一份，切换方式不会丢已填的内容。

日期面板上的标记怎么读

标记含义
底色浅红 / 浅金这天有报警 / 预警。
右上角 休 / 班法定放假 / 调休上班。
左上角蓝点这天是初始值日（V0 的来源日）。
底部横条（红/金/绿）这天已录入，颜色表示当天最严重的预警等级。
日期数字变灰周末。

3.2　总览表格录入

一行 = 一个测点（不是一条记录）。列的含义：

列含义注意事项
测点 / 类型点号和观测类型。类型决定后面三格哪几个能填。
初始值 V0 (m)显示该点各观测项的 V0，带来源标签 显式 或 首期。这里不能改。要改 V0 去测点管理页。
沉降读数 (m)当天沉降读数，占位符 留空=缺测。纯位移点这一格显示 -。
位移 X (m) / 位移 Y (m)当天水平位移读数。纯沉降点这两格显示 -。
录入状态未录入 / 已录入 / 缺测 / 异常 / 作废。按测点聚合：只要有一个观测项缺测，整行就显示"缺测"。
预警状态正常 / 预警 / 报警，或 —。报警优先于预警。显示的是所选日期那一天的状态。

单位要当心：录入框里填的是米（如 2.9775），保存后系统内部按毫米存（2977.5）。测点管理页的「初始值(mm)」那一列显示的是毫米原值——两边数字差 1000 倍是正常的。

录入框没有任何格式校验（能打字母、能打两个小数点）。提交时系统按数字解析，写错了会保存失败或算出怪数。建议只用数字和小数点，别粘贴带单位的文本。

3.3　顺序录入（键盘流）

一屏一个测点，适合现场一个一个念着录。切换方式：工具条 顺序录入。

控件 / 按键作用注意事项
进度 第 N / M 个测点当前在第几个点。—
进度条 x / y 项已填已填字段数 / 应有字段数。按"这一格有内容"计数，填了字母也算已填。
输入框（带后缀 m）填读数，标签是 沉降读数 / 位移 X / 位移 Y。占位符 留空=缺测。
已有值时右侧会显示灰字 已录 x.xxx。
回车跳到本点下一格；在最后一格回车 = 跳到下一个点。在最后一个点的最后一格回车 = 直接保存（省一次点击）。
↑ / ↓上一个 / 下一个测点。切换后自动聚焦输入框。
上一个 / 下一个同样的切换，用鼠标点。第一个点时「上一个」是灰的，最后一个点时「下一个」是灰的。
保存本期观测与工具条那个按钮同一个动作。最后一个点下方会提示"按回车或点保存即可提交"。

3.4　保存与更正：改一个数会发生什么

点「保存本期观测」后，系统逐测点比对"你现在填的"和"系统里已有的"：

情况系统怎么处理你会看到
这一期还没有记录新增一条（留空的也会新增一条"缺测"记录）。汇总提示 保存完成：新增 N 条
有记录、值没变不动。如果整张表都没变：本期数据无变化，无需保存
有记录、值变了更正：旧记录标记为"已被更正"并保留，新值另存一条。先弹确认框 确认更正以下数据？，逐行列出 1.234m → 1.240m（或 → 缺测）

更正确认框里那句「原值将保留（可追溯），新值生效」不是客套话：旧读数不会被删，只是不再是"当前有效值"。所以改错了还能查回来，也所以改历史期会让报表重算——已经出过的日报不会自动变，需要重新导出。

3.5　自动生成数据：演示与补数

入口：记录页 → 自动生成数据（闪电图标）。用于演示、培训，或在真实数据还没到时先把流程跑通。

字段作用注意事项
开始： / 结束：生成的日期范围。默认"今天前 6 天 ~ 今天"。结束早于开始会提示。
生成范围里的每一天都会有一条读数。
每日缺测概率：N%
滑块，默认 0%		每天被随机判为"缺测"的概率（0~50%）。想模拟真实台账那种"偶尔漏测"就调大一点；演示用保持 0。
随机种子（可选，固定可复现）填一个数，同样参数每次生成同一批数据。要在会上演示、想保证每次都一样，就填一个固定值（如 20260801）。
全站仪观测模式
开关，默认关		开启后叠加"每次架站"的公共误差：同一期所有位移点会一起偏一点。只影响水平位移（沉降是水准仪测的，不受影响）。
开启后还要填对中误差、定向误差、工作距离。

点「开始生成」之后

情况会发生什么
范围内都是空日期直接生成，不打扰你。
范围内已有数据弹窗问你怎么办，三个选项见下。
选项含义什么时候选
跳过它们，只填空白的那 N 天 已有数据一律不动。 涉及真实数据时的默认选项，也是最安全的。
替换掉自动生成的那 N 天 只重做系统自己生成的演示数据，真实数据仍然跳过。 之前造过演示数据、想重新造一批。
连真实数据一起替换（N 天 / 约 M 条） 真实读数会被顶替——但原值不删除，标记为「作废」保留。 基本不要选。选了会弹红色警告，并建议你先去「数据备份」做快照。

生成完成后，结果会以卡片形式留在页面上（弹窗会自动关闭），列出"生成了多少条、替换了几条、跳过几天"，还会给一张"原读数 → 新读数"的对照表，让你确认数据确实换过了。

控件作用注意事项
收起关掉结果卡片。再生成一次也会覆盖。
清理自动生成的数据
红色小按钮，在生成弹窗里		删除整个项目的全部自动生成数据。没有日期范围限制——点一下清的是这个项目所有演示数据，不是当前选的区间。
真实录入/导入的数据不受影响。
操作前有气泡确认。
