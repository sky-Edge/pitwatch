1它能帮你做什么

把现场每天都在重复的那套活——录入 → 计算 → 判断 → 画曲线 → 做日报 → 归档——全部自动化。你只管把读数录进去，剩下的系统算。

录入 / 导入观测读数→ 自动算本次变化→ 自动算累计变化→ 自动算速率
↓
自动判断预警→ 生成曲线→ 逐期对比→ 一键导出日报→ 自动备份

四条设计原则（为什么不担心数据被弄乱）

原始数据只增不改填错了只能走「更正」，旧值永久保留、可追溯，任何操作都不会覆盖或删除原始读数。
计算可复算同一批原始数据，任何时候重新计算结果都一样，不存在"算一次变一次"。
规则可配置预警阈值、正负号方向都按项目和规范配置，不是写死在程序里。
绝不静默覆盖重复导入、日期冲突的数据一律跳过并明确报告，不会偷偷盖掉。

2打开与关闭

打开

  1. 解压后，双击文件夹里的 「启动系统.bat」（或直接双击 MonitorSystem.exe）。
  2. 会弹出一个黑色窗口，几秒后浏览器自动打开系统页面。
  3. 如果浏览器没有自动打开，手工在地址栏输入：http://127.0.0.1:8000
提示第一次启动稍慢（约 5～10 秒）属正常。黑色窗口里滚动的是运行日志，不用管它，但不要关。

关闭

直接关闭那个黑色窗口（点右上角 ✕，或在窗口里按 Ctrl+C）：

  • 全部服务随之停止，不会残留后台进程；
  • 每次退出会自动备份一次数据库，存在 database\backups\ 里，保留最近 30 份。
注意页面报「网络错误」或打不开，通常就是黑色窗口被关掉了。重新双击启动即可，数据不会丢。

3第一次使用：先看个示例

刚打开时系统里是空的。想先看看它长什么样、能出什么成果，最快的办法是：

项目列表页 → 点 「先看个示例」

系统会自动建好一个演示项目（含测点、预警规则和几期观测数据），你可以直接点开看曲线、逐期对比、导出一份日报——熟悉完可以直接把它删掉。

提示示例项目里的数据都标记为「自动生成」，和你的真实录入数据严格区分，清理时不会碰到真实数据。

5这些地方能帮你省事

系统里藏着不少"顺手"的设计。提前知道能少点几下鼠标、少犯几个错。最实用的集中放在这一节。

5.1 录入用键盘，手不用离开键盘

「逐日录入」页有两种录入方式（页面顶部可切换）。现场读数多的时候用 「顺序录入」：一屏只显示一个测点，全程键盘操作。

操作作用
Enter跳到下一格；在本测点的最后一格按回车 = 直接跳到下一个测点
↑ ↓上一个 / 下一个测点（敲错了就地回退，不用去表格里找）
刚进页面光标自动落在第一个输入框，不用先点一下
留空= 当天没测（缺测），不会当成 0
还有个细节切到某个测点时，之前录过的值会自动预填进输入框，方便你对着核对、微调，而不是空白重敲；输入框旁边还会显示这个测点已录的值。顶部有"第 N / 总数"的进度，知道还剩多少。

5.2 从"待办"点进去，直接落到那一条

项目列表顶部那块 「需要关注」（哪些测点报警/预警了），点右边的「去处理」——不是把你丢到录入页让你自己找，而是：

  • 自动切到那一天的录入界面；
  • 那条测点整行用蓝色竖条标出来，并自动滚动到它；
  • 页面顶部同时说明是哪一项触发的，以及"读数有误可直接修改，改完点保存"。

5.3 日历上的横条 = 那天有数据

所有日期选择器里：带横条的日子 = 有观测数据，灰色的 = 没有数据、点不动，面板底部有图例说明。

导出页如果选了一段"里面一期都没有"的区间，会直接提示你，而不是默默什么都不发生。

5.4 Excel 导入：几处省事的做法

遇到的情况可以这样处理
要补好几期历史数据一次多选几个文件（每期一个），系统逐个核对后列成一张总清单，确认一次全部导入
点号写法对不上预览页的「测点匹配」中，相似点号直接下拉选映射；系统里确实没有的可以选「自动建点」；不想导的选「跳过」
台账里没写观测日期预览页会提示，你补选一个日期即可导入（不选就不导入——系统不替你猜日期）
该日期已经录过数据默认跳过、不覆盖，并在清单里标成"冲突"给你看
改了观测日期系统自动按新日期重新核对（冲突关系会变）；同时重置你之前勾的"排除"并明确告诉你——避免错位排除掉别的行
表头认不出来页面会直说"把该文件的表头文字发我，我加识别规则"，而不是只报一个错

5.5 导出：一次操作出多期

  • 选一天 = 导出单份文件；选一段日期 = 把这几期打包成一个 ZIP 一次下载；
  • 母版只上传一次，之后每期自动套用；同名上传会自动替换旧版，下拉里不会堆一堆重复项；
  • 一份母版可以给好几个项目用：上传时勾好"作用于哪些项目"（或设为通用），不用每个项目各传一遍；改版式时同名重传一次，原先绑定的项目自动继承；
  • 测点比母版多时自动补行/补块，导出后还会弹提示告诉你在哪张表补了哪几个点；
  • Word 日报只支持单期（要导几天就把起止日期选成同一天）。

5.6 防呆设计（不是限制，是保护）

你可能担心的事系统的做法
手滑重复保存数据没变化时直接提示「本期数据无变化，无需保存」，不会产生重复记录
改错了值弹「原值 → 新值」让你确认；改完旧值标记为"已更正"永久保留，随时可查
误删项目 / 测点常规操作只有「归档 / 停用」，数据全留着；「彻底删除」需要手动输入编号确认，且删除前自动备份
还原备份会盖掉现在的数据还原前系统自动再快照一次，等于留了后悔药
演示数据混进真实数据演示数据单独标记、可一键清理，真实录入与导入的数据不受影响

5.7 生成演示数据：先预检，再决定怎么处理

「自动生成数据」不是直接闷头开干：先预检范围内哪些日期已经有数据，由你决定——跳过 / 只替换之前自动生成的那些 / 连真实数据一起替换（最后一种对真实数据只作废、不删除）。

生成完还会给一张 「旧值 → 新值」对照表。因为替换前后读数只差一两毫米、记录条数完全一样，不给对照你根本看不出到底换没换。

5.8 看数据时的小参照

  • 逐期对比的「速率」列，鼠标悬停会显示算式：本次变化 ÷ 间隔天数——除数是多少一目了然；
  • 曲线图里报警点红标、预警点黄标，一眼看到问题点在哪；
  • 预警规则是"双控"：累计值和变化速率任一项超标即触发，与规范口径一致；预设值只是起点，实际以设计文件为准，可直接修改；
  • 预警事件是派生数据，可以随时「重新计算预警」整体重建，不会影响原始读数。

6建项目与建测点

5.1 建项目

项目列表页 →「新建项目」，填三项即可：

项目编号说明
项目编号如 PRJ002，全系统唯一、不可重复
项目名称如 8号基坑
地点工程位置 / 标段
正负号规则（可选）决定"方向"的说法：沉降正值表示下沉还是隆起、位移正值表示向坑内还是向坑外。不填就按行业惯例（沉降正=下沉，位移正=向坑内）

一次要建好几个基坑？用「批量建项目」

项目列表页 →「批量建项目」：

  1. 选一张「点号 + X / Y / Z」的清单文件（Excel）；
  2. 在预览表里把点分组——哪些点属于哪个基坑，直接在下拉里选或输入基坑名；
  3. 给每组选初始值日期（也可统一设成同一天）；
  4. 需要的话设「点号规则」（前缀 + 起始序号 + 是否补零），系统按清单顺序自动编号，界面里并排显示"生成后的点号 / 原表里的名字"；
  5. 点「分组建项目」，一次把项目、测点、初始值全部建好。
提示项目编号已存在时会复用那个项目；项目内已有点号相同时会跳过并报出来，绝不会覆盖已有初始值。

5.2 建测点

方式一：单个新建

项目内 →「测点管理」→「新建测点」：填编号（如 JJC1）、选类型（沉降 / 水平位移 / 沉降+位移——同一根桩两项都测选这个）。
初始值可以现在填，也可以留空——留空时系统自动取第一次有效读数作为基准（V0）。

方式二：批量新建（几十个测点一次搞定）

「测点管理」→「批量新建」→ 从 Excel 里复制多行粘贴进去，每行一个：

编号,类型[,初始值mm][,位置]　例如：JJC1,沉降+位移,4907000,1#钢板桩桩顶

点「校验并预览」后会自动分成三组：可创建 / 跳过（编号已存在）/ 错误（格式不对），确认无误再一次性创建。

什么是初始值（V0）它是后续所有"累计变化"的基准——累计变化 = 本次读数 − 初始值。所以初始值那一期很关键，通常取开挖前的首次观测。

7录入观测数据（三种方式）

方式一：用 Excel 台账导入（推荐，尤其补历史数据）

项目列表 →「Excel 导入」→ 把当天填好的台账文件拖进去（可以一次选多个，每期一个文件）。

系统会自动识别数据表、观测日期和列含义，并把读数从 米（m）换算成毫米（mm） 入库。全程先预览、后落库，你确认了才会写进系统。

预览页你要看一下三件事

看什么含义与处理
✓ 可导入正常数据，确认后一起入库
⚠ 冲突该日期该测点已有数据 → 默认跳过、不覆盖（避免手滑把真实数据盖掉）
✗ 错误例如类型不匹配、点号找不到，需要处理或排除

点号和系统里的对不上？有「测点匹配」面板

  • 写法相近的（如台账里是 JJC-01、系统里是 JJC1）→ 系统给出候选，你下拉选「映射到已有测点」即可；
  • 系统里确实没有的点号 → 可以选「自动建点」（类型按该点的数据自动推断）；
  • 不想导入的点 → 切到「跳过」。

台账里没写观测日期？

预览页会提示「未识别观测日期」，你选一个日期（比如该批数据的采集日）就能正常导入。
不选就不会导入——系统不会替你猜日期。

注意改了日期之后要重新核对：换了日期，"会不会和已有数据冲突"可能就变了，界面会自动重算。另外改了日期会清空你之前勾的"排除"选择，这是有意的（免得错位排除掉别的行）。

方式二：页面上逐日录入

项目内 →「逐日录入」→ 选日期 → 每个测点填读数（单位 m）→「保存本期观测」。页面提供「顺序录入」（一屏一个测点、全键盘）与「总览表格」（一屏看全部）两种方式，顶部可切换。

省事提示读数多的时候用「顺序录入」：回车跳下一格、↑↓ 切换测点，切到某个测点还会自动预填该点已录的值。完整清单见 第 5 章「这些地方能帮你省事」。
  • 留空 = 缺测：保存后自动标记"缺测"，不参与计算，曲线也不会断；
  • 保存后立即显示每个测点的预警状态；
  • 页面上的日历里，有横条的日子表示那天已录入，灰色表示没有数据。

填错了怎么办？

直接在输入框里改成正确值 → 弹窗会列出「原值 → 新值」让你确认 → 确认后新值生效、旧值标记为"已更正"并永久保留。
整条误录的，可以用「作废」——作废后不参与计算，但记录仍在，随时可查。

方式三：自动生成演示数据（给试算和汇报用）

「逐日录入」页 →「自动生成数据」：选一个日期范围即可生成一段观测数据。

  • 生成的数据标记为「自动生成」，与真实录入严格区分，可一键整批清理；
  • 遇到范围内已有数据的日期，会先问你怎么处理（默认跳过；也可只替换掉之前自动生成的那些，或连真实数据一起替换——后者对真实数据只作废、不删除）；
  • 生成完成后页面会给出「旧值 → 新值」对照，方便确认真的换了。

「全站仪观测模式」是什么？

打开这个开关后，生成的数据会模拟全站仪每次架站的误差：对中偏差、后视定向偏差由当期所有测点共同承担，所以同一期的各个点会"一起偏一点"——这正是真实全站仪数据的特征，比各跳各的更接近现场。

三个参数按你现场的实际情况填（默认值按普通现场水平给）：

参数含义
对中误差每次架站的对中+整平偏差（极限值）。三脚架+光学对中器一般 2mm；有强制对中装置可填 0.5
定向误差后视定向的中误差。正倒镜取中约 2～3″；单盘观测 5″ 很常见
工作距离仪器到基坑的平均距离，只用于把角度误差折算成毫米
提示这个模式只影响位移。沉降是水准仪测的，每站独立、和架站位置无关，所以不受影响。

8看结果：曲线、对比、预警

这些全部是系统自动算的，你不需要手工做任何计算。

想看什么去哪儿看内容
单个测点最新状态逐日录入页「预警状态」列：红 = 报警、黄 = 预警、绿 = 正常
项目整体情况项目列表页每行显示报警 / 预警数量，顶部横幅点名有报警的项目，点「去处理」可直接定位
变化趋势曲线图多个测点的累计变化曲线，报警点红标、预警点黄标；沉降曲线与水平位移曲线可切换
逐期明细逐期对比每一期的读值、本次变化、累计变化、速率、变化方向、间隔天数、预警状态
历史预警预警事件预警 / 报警事件清单，可随时「重新计算预警」
数据质量预警事件页顶部「突变疑似」（单期变化异常大）、缺测统计 —— 只提示，不删数据
缺测了怎么看某天没测，下次观测的"本次变化"会自动与最近一次有效值比较，并标注间隔了多少天，速率按实际间隔天数折算——曲线不会断，速率也不会失真。

9预警规则与一键修正

8.1 配置预警规则

项目列表 →「预警规则」（在项目行的「更多」里）：

  • 内置规范预设库：
    · GB 50497-2019《建筑基坑工程监测技术标准》（钢板桩一 / 二 / 三级）
    · 八号基坑实测模板（沉降 30mm / 10mm·d⁻¹，位移 20mm / 3mm·d⁻¹）
    · 自定义空白
  • 选预设后会带出控制值（预警）和报警值两档；
  • 每档都是双控：累计变化限值（mm）+ 变化速率限值（mm/d），任一项超标就触发；
  • 数值都可以直接改——以设计文件为准；
  • 每个项目独立配置，互不影响。
这里的「控制值」就是报表上那两列 规则里的控制值（累计变化量 / 变化速率），和导出报表里「控制值」两列是同一个数： 在这里改限值，导出的报表跟着变（母版里原来印的旧数字会被覆盖掉）； 项目没配规则时，报表才保留母版自带的那组数字。两处永远对得上，不会出现"表里写 30/10、系统按 20/2 判"。
台账里已经印着控制值？可以一键搬过来 导入 Excel 时，如果识别到台账上写着控制值（如沉降 30mm / 10mm·d⁻¹、位移 20mm / 3mm·d⁻¹）， 系统会把它和当前规则并排显示，对不上会标出来；勾上「导入时把台账里的控制值同步到本项目预警规则」， 导入的同时就把限值配好（只改「控制值」，报警值不动 —— 台账上没有报警值的依据）。 默认不勾：导入数据就只是导数据，判定口径要你点头才改。

8.2 一键修正报警值

项目内 →「预警事件」页 →「一键修正报警值」。

用途：当报警是因为读数抄录错误（或现场数据本身需要按限值整理）时，一次性把触发报警的那几条读数更正到限值以内，不用一条条手改。

点按钮后的流程：

  1. 先预检（这一步只看不改）：告诉你要改多少条，并给出每条的「旧读数 → 新读数」对照；
  2. 你可选范围：只修报警，或预警 + 报警一起修；
  3. 点确认后才真正落库；修完的结果会留在页面上（不是弹窗里一闪而过），可以直接看到改了多少条、当前还剩几条。
原值不会丢每条修正都走「更正」：原读数标记为作废并永久保留，新记录备注里写清「旧值 → 新值（原来触发的是哪条限值）」。一条都不删。
为什么条数会比事件数多把前一期的值往下调之后，后一期相对"新的上一期"的变化量就变大了，可能带出新的超限期。系统会自动算到收敛为止，所以"78 条事件 → 改了 115 条"是正常现象。

10出成果：导出日报

9.1 先上传一份「母版」（每个报送版式只做一次）

项目列表 →「导出日报」→「上传报送母版」→ 直接点「选择整卷文件上传」，挑一份你已经填好的整卷日报（比如上期的报送文件）就行。

名字不用先想好：不填就用文件名当名字；想改的话，在上传前的输入框里填，或者上传之后在导出页选中这份母版、点旁边的「重命名」再改。先挑文件还是先起名字都行，顺序随意。

系统会自动"学会"这份母版里哪些格子会变、怎么填——封面日期、签字期次、天气、两张数据表的数据区等等。之后每期一键产出的就是和母版一模一样的整卷。

换版式不用改程序换基坑或换报送格式时，再上传一份新母版即可，新旧模板可以并存；同名上传会自动替换旧版，不会堆积重复项。
一份母版可以给多个基坑用（不用每个项目各传一遍） 上传时下面有一个「这份母版作用于哪些项目」：几个基坑版式一样，就一次性把它们勾上（或者直接勾「所有项目通用」）。 传完之后，这些项目在导出页都能选到这份母版。
想改范围：导出页选中这份母版 → 点「设置适用项目」。
改了版式怎么办？把改进后的母版用同一个名字重新上传就行 —— 它原先绑定的项目会自动继承， 不用一个个重新勾。这就是"改一次、全体跟随"。
重命名只改显示名称改的是模板列表里显示的名字，母版文件和已识别好的版式都不受影响，改名后直接导出即可。名字不能和已有的母版重名（否则下拉框里两个一模一样的名字分不清）。

9.2 每期导出

「成果导出」页 → 选报告模板（选你上传的母版，或不选=内置标准日报）→ 选天气 →「导出观测日报」。

  • 日期选择器里，带横条的日子表示那天有观测数据，灰色的表示没有数据、不可选；
  • 可以选一段区间批量导出（多期打包成一个压缩包）；
  • 导出时数据表里的初始值 / 上次测值 / 本次测值 / 累计 / 变化 / 速率全部由系统算成数值写入，换台电脑打开也不会变；
  • 概况、分析、成果提交三页的整段文字按本期数据自动重写（见下方专条）；其他固定版式内容原样保留；
  • 工程名称除外：母版里凡是写着别的基坑名的地方（封面工程名称、签字栏、 两张表的"监测工程名称／工点名称"、以及"本次监测工作为××基坑…"这类叙述文字）， 导出时都会自动换成你项目的名字——母版是拿别的基坑那期报表存下来的也不会串名。
概况 / 分析 / 成果提交：这三页的文字系统自动生成 母版是从别的工程那期报表另存来的，这三页里往往整段都是别人的内容（比如分析页写的是 "地表沉降 DBC05-01""测斜 QCX1"，结论页写的是别的工地名）。每期手工改十几段不现实，所以导出时系统会按本期真实数据重写：
· 分析页：每个监测类别一段——本期累积变化量极值、极值出现在哪个测点、达到预警/报警指标的测点有几个、分别是谁；
· 成果提交页：结论按"有没有超限点"分两种写法；成果清单只列你项目实际有的类别（母版多列的几种不会跟着印出来）；
· 概况页：本周监测日期、类别、次数，以及工作量表里的项目名与点次。
母版里多出来的旧段落会被清空（这是关键：不清就是在发别人的内容）。
⚠ 现场巡视那句不写"未发现异常"——是否发现异常要靠现场人员判断，系统没有巡视数据，不替你下结论； 导出后如需补充，直接在 Excel 里改那一句即可。
数值显示与列宽 报表里的数按两套格式写，不会出现 20.00000、3413192.92900 这种拖着一串零的样子：
· 初始值 / 上次测值 / 本次测值 / 控制值 → 常规格式：整数就是整数（20、30），有小数才带小数（3.119）；
· 上次累计变化量 / 本次累计变化量 / 本次变化量 / 变化速率 → 带小数点：整数也写成 0.0、-4.0，有小数就照实写（-1.5、0.125），多余位数不补零。
列宽只在内容放不下时自动加宽（比如水平位移表里的坐标），母版自己定好的列宽一律不动 —— 免得把 A4 版式撑破。
测点比母版多怎么办比如母版是 8 个点、你现在的基坑有 12 个点：系统会自动补行，把多出来的测点接着往下排，位置不够时自动把下面的说明、结论、签字栏整块下移——不会再把多出来的点悄悄丢掉。表右侧的「原始数据区」（X/Y/Z 坐标小表）同样会自动补。
报表里看不到"预警"？这是有意的导出的报表不显示预警等级，母版里自带的、别的基坑的「预警统计」旧数据也会被清空（那些不属于你的项目）。预警信息请在本系统的「预警事件」页面查看。

9.3 Word 日报

「成果导出」页还提供 Word 日报导出，内容与页面数据一致。

11数据安全与备份

规则说明
原始数据只增不改观测记录不允许被覆盖或物理删除，填错走「更正」，旧值永久保留
有数据就不能随便删已有观测数据的项目 / 测点默认只能「归档 / 停用」，历史数据永久保留
彻底删除要二次确认确需清理时用「彻底删除…」，需要输入项目编号确认，且删除前自动备份一份，可回退
重复导入有保护同一天同一测点已有数据 → 跳过并报告，绝不静默覆盖
异常数据不删除突变、缺测只做标记提示，交由人工核对
备份可还原关闭系统时自动备份；顶栏「数据备份」也能手动「立即备份」，列表里可对任一备份点「还原」（还原前自动再快照一次）
建议定期把 database\backups\ 文件夹拷到 U 盘或网盘，多一层保险。

12常见问题

Q1　浏览器打不开页面 / 提示网络错误？
多半是那个黑色窗口被关掉了（服务已停）。重新双击「启动系统.bat」，等几秒再刷新页面。数据不会丢。
Q2　导入时提示点号不存在 / 对不上？
预览页会出现「测点匹配」面板：相似的点号可以从候选里选「映射到已有测点」，确实没有的点号可以选「自动建点」，不想导入的切「跳过」。
Q3　同一天录了两遍会不会冲突？
不会。第一遍保留，第二遍（无论手工录入还是 Excel 导入）会被识别为冲突并跳过，可以放心操作。
Q4　某天没测（缺测）怎么办？
录入时把那一格留空保存即可，系统记为"缺测"。下次观测的本次变化会自动与最近一次有效值比较，并标注间隔天数，速率按实际间隔折算。
Q5　预警一直在，怎么消掉？
先核实数据：如果是抄录错误 → 更正读数后预警自动重算消失；如果是现场确实超限 → 那是真实情况，应当按方案处置；如果确认是阈值设得不合适 → 到「预警规则」调整。批量处理可用「一键修正报警值」。
Q6　导出的 Excel 里累计变化和母版里的对不上？
系统按"读数之差"严格计算（初始值那期就是基准）。母版里若是人工填的数可能有出入——以系统计算的为准，它与「逐期对比」页显示的一致。
Q7　导出的报表里没有预警列 / 有别人基坑的数据？
报表有意不显示预警；母版自带的「预警统计」等内容如果来自别的基坑，会在导出时被清空（保留标题表头）。预警请看系统的「预警事件」页。
Q8　数据存在哪里？会不会联网上传？
全部存在程序文件夹里的 database\monitor.db 这一个文件里，纯本地、不联网、不上传。备份在 database\backups\。换电脑时把整个文件夹拷过去即可。
Q9　母版原件能删吗？
不能。上传的母版存放在 templates\ 目录里（新传的在 templates\_library\ 下），它是导出的底模，删了导出会失败。如果下拉里提示"原件缺失"，重新上传一份即可。另外：删除项目不会删掉被别的项目共用的母版，只会解除这个项目的关联。
Q10　怎么把某个基坑的活干完、不再显示在列表里？
用项目行「更多」里的「归档」——项目从常用列表里收起（可切换"全部（含已归档）"查看），数据全部保留。需要时「恢复在用」。
Q11　导出的分析/结论页里那几句话是谁写的？能改吗？
是系统按本期数据自动生成的（母版里原本那几段是别的工程的，已经不再使用）。想改口径请把母版里那几页的版式调整后重新上传（比如多加几段的位置），文字内容每期都会被本期数据覆盖。
现场巡视那句只写"现场巡视 1 次"，不写"未发现异常"——需要的话导出后在 Excel 里补一句即可。
